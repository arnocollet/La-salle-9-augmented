# Règles de publication

Ce projet est personnel et ne nécessite pas de revue par pull request.

Quand l’utilisateur demande de publier, publier directement les modifications avec :

1. vérifier les fichiers modifiés ;
2. exécuter les vérifications utiles ;
3. créer un commit explicite ;
4. pousser la branche avec `git push`.

Ne jamais créer de pull request, même en brouillon, sauf si l’utilisateur le demande explicitement.

Ne pas publier automatiquement après une modification si l’utilisateur n’a pas demandé de publier.
